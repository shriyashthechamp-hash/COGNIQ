COGNIQ is an AI-powered cognitive intelligence system designed to detect conceptual learning gaps before academic failure occurs.

Unlike traditional assessment systems that measure marks, COGNIQ models:

- Concept Mastery
- Stability of Understanding
- Academic Risk
- Cognitive Confidence

Students often progress through Classes 9–12 without mastering foundational concepts. Traditional classroom systems:

- Do not track concept-level understanding in real time  
- Detect failure only during exams  
- Cannot adapt to individual learning instability  

As learning gaps compound, students lose confidence and disengage academically.

COGNIQ addresses this silent academic instability.

## 🧠 Cognitive Modeling Engine

### 1️⃣ Weighted Concept Mastery (Diminishing Gain Model)

$$M_{new} = M_{prev} + \alpha D (1 - \frac{M_{prev}}{100}) - \beta D (1 - C)$$

- Models learning saturation
- Prevents inflated mastery spikes
- Difficulty-weighted updates

---

### 2️⃣ Stability Index (SI)

$$SI = \frac{Correct\ Answers}{Total\ Attempts} \times 100$$

Measures consistency of understanding.

---

### 3️⃣ Concept Instability Score (Volatility)

$$CIS = \sqrt{\frac{1}{n} \sum (C_i - \bar{C})^2}$$

Quantifies conceptual inconsistency.

---

### 4️⃣ Composite Academic Risk Index

$$R = w_1(100 - \overline{M}) + w_2(100 - SI) + w_3 CIS + w_4 W_c$$

Where:
- $\overline{M}$ = Average Mastery
- SI = Stability Index
- CIS = Instability Score
- $W_c$ = Weak Concepts Count

This multi-factor model prevents oversimplified risk evaluation.

---

### 5️⃣ Cognitive Confidence Index

$$CCI = \frac{\overline{M} \times SI}{100}$$

Confidence is modeled as the interaction between performance strength and stability.

---

### 6️⃣ Predictive Performance Decline

$$PD = R \times (1 - SI/100)$$

Projects potential academic deterioration if no intervention occurs.

---

### 7️⃣ Cognitive Recovery Velocity

$$CRV = \frac{M_t - M_{t-1}}{\Delta t}$$

Tracks improvement momentum across sessions.
